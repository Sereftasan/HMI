How to write Kaban HMI help files

POINT Three example files sit beside this one. Copy the closest one and replace its content – that is faster and safer than starting from a blank page.

Unit_Robot_Top_Clamping.html – what a unit is
Alarm_Robot_Clamping_Failure.html – what to do about one alarm
Axis_Robot_X.html – what an axis is, and how it is homed and maintained

1. The three kinds, and who reads them

KindOpened fromRead whenAnswers
Unit sheetThe ? on a unit on a Manual Movement pageAny time, often before a fault What is this thing, where is it, what is fitted to it, how is it set?
Alarm sheetThe Help column of the alarm, and the unit's ? while its alarm is active With the machine stopped and someone waitingWhy did this alarm happen and what do I do now?
Axis sheetThe ? on the Axis Settings rowDuring setup or maintenance What drives this axis, what are its limits, how is it homed and maintained?

2. Where the files go

A file that belongs to one machine goes in that machine's project, in its Help folder: 

Kaban.Machines.FA2010\Help\Unit_Robot_Top_Clamping.html

A file shared by every machine (a supplier's manual, the cylinder troubleshooting manual) goes in KabanHMI\Help; every machine's build copies it. Add a new file to the machine's project file once, and the build puts it in bin\Debug\Help, which is where the HMI looks.

3. Naming

KindPatternExample
UnitUnit_<unit name>.<language>.htmlUnit_Robot_Top_Clamping.en.html
AlarmAlarm_<what happened>.<language>.htmlAlarm_Robot_Clamping_Failure.en.html
AxisAxis_<axis name>.<language>.htmlAxis_Robot_X.en.html

Use the name exactly as it appears on the HMI, with underscores for spaces. No dates or version numbers in the file name: the file is the current one, and its history belongs in your document system.

4. How a file is attached

To a unit

In the designer, select the unit and set HelpFiles under the Help group. The picker lists file names, separated by ;. Several files are allowed – the ? then opens a list: 

Unit_Robot_Top_Clamping.html;Robot_Clamp_Photo.png

To an alarm

On Machine Parameters → Alarms, in the Help column of that alarm, or directly in the machine's Alarms.json: 

{
  "PlcAddress": "M840",
  "TagCode": "Robot_Clamping_Alarm",
  "Severity": "Fault",
  "PlcNumber": 1,
  "Translations": { "EN": "Robot Clamping Alarm", "TR": "Robot Sikma Alarmi" },
  "HelperKeys": [ "Alarm_Robot_Clamping_Failure.html" ]
}

An alarm raised by a unit also shows that unit's own help, so don't repeat the unit description in the alarm sheet.

5. What the HMI can open

FormatUse it forNotes
.htmlEverything you write yourself Best choice: opens instantly, prints, and the program can show one section of it
.pdfSupplier manualsOpens at page one; say in the entry which section to turn to
.png, .jpgA photograph of the real partKeep under about 1 MB

6. Writing rules that matter on the shop floor

RuleWhy
Safety first, in its own box at the topIt is read while the machine is stopped and someone is in a hurry
Checks in order, cheapest and safest firstMost faults end at the second or third check
Give BOTH outcomes of every check"If yes … if no …" is what keeps the reader moving
Name devices exactly as the HMI does (M840, M233)So the reader can find them on the monitor page
Short sentences, no abbreviationsThe reader may not have written the document, or share your first language
Say when to stop and call for supportRepeated resets of a real fault damage the machine
One subject per fileThe HMI opens exactly what was asked for; a combined document forces searching

9. Languages

A document is referred to by ONE name everywhere – in the designer and in Alarms.json you always write Unit_Robot_Top_Clamping.html, without a language. On disk you keep one file per language: 

Help\Unit_Robot_Top_Clamping.en.html      English (the master)
Help\Unit_Robot_Top_Clamping.tr.html      Turkish
Help\Unit_Robot_Top_Clamping.ru.html      Russian
Help\Robot_Clamp_Photo.png                no language needed

The HMI opens the file for the language the operator has selected. If that language has not been translated yet it opens English, and if there is no language suffix at all it opens the plain file. So:

This meansWhy it matters
Nothing is re-pointed when a translation arrivesDrop the new file into Help, add it to the project, done – the operator simply stops seeing English
A machine can ship with only some languages doneA missing translation never leaves an operator with nothing
A translator receives one whole fileNo string lists, no tooling; they see the tables and the context they are translating
Supplier manuals follow the same ruleMR_J4_TroubleShooting.en.pdf beside a translated one, referred to by the one name

Rules for translators

RuleReason
Keep the file name, section order and table structure identical to the English masterAnyone comparing the two can see at a glance what is missing
Never translate device addresses (M840, M233), part numbers or unitsThe reader has to find them on the HMI and in the cabinet
Translate the safety box first and most carefullyIt is the part that must be understood without a second reading
Set <html lang="tr"> and keep <meta charset="utf-8">So accented characters show correctly everywhere
When the English master changes, change every translation in the same commitOtherwise the machine quietly ships two different instructions

Alarm_Robot_Clamping_Failure.tr.html beside this file is a finished example of a translated sheet.

10. Adding a photograph

Put the image file in the same Help folder, add it to the unit's HelpFiles, and reference it from your page if you want it inline: 

<p class="fig"><img src="Robot_Clamp_Photo.png" width="520" alt="The clamp seen from the exit side"></p>
<p class="cap">Fig. 2 - the clamp seen from the exit side</p>

Photograph the part in place, with enough surroundings to find it, and with the guard open in the same way the reader will open it.

11. Before you hand it over

Check
Open it from the HMI itself, not from the folder – that proves the name and the link are right.
Have someone who did not write it follow it once on the machine.
Every device number in the file matches the PLC program and the HMI.
Nothing in it tells the reader to bypass a guard, an interlock or a light curtain.

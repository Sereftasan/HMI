M840 – Robot Clamping Alarm

CAUTION Eliminate the cause and make the area safe before resetting. Before touching the clamp, isolate the electrical and pneumatic supplies and exhaust both sides of the cylinder: a clamped cylinder holds pressure and can move when air is restored. Never bypass the guard interlock to clear this alarm.
POINT Alarm: the clamp command was issued but the clamped sensor did not confirm within the monitoring time.
Unit: Robot Top Clamping – clamp M656, release M657, clamped sensor M233.
Work down the table in order. Most cases stop at detail 2 or 3.

Checks, in order

No.CauseCheckResultAction
1The profile is not in position, so the clamp cannot close on it Look at the transfer station. Is the profile fully against the reference face? The profile is short, skewed or missing Clear the station, correct the upstream transfer, restart the cycle.
The profile is in positionGo to check 2.
2The sensor is out of position or has failed Clamp by hand from Manual Movement. Does the left button's lamp light at the end of the stroke? The clamp closes but the lamp stays dark Re-set the sensor (see the unit sheet), or replace it if it does not switch at any position.
The lamp lightsThe alarm is a timing problem – go to check 5.
3No air, or not enough pressure Read the supply gauge with the machine running. Below 5.5 bar Restore the supply; check the filter/regulator and the main line for leaks.
6 bar and steadyGo to check 4.
4The valve does not shift Command the clamp and watch the valve's coil LED, then press the manual override on the valve. LED off, but the override moves the clamp Electrical fault: check the wiring from the output to the coil, then replace the coil.
LED on, the clamp still does not move Spool stuck or contaminated: clean or replace the valve, and check air quality.
5The stroke is too slow for the monitoring time Time the clamping stroke by eye from Manual Movement. Noticeably slower than about half a second Open the exhaust throttles a little, check for a kinked hose, and check the clamp pad for build-up.
The stroke looks normal Have the monitoring time reviewed in the PLC program – request support.

After the repair

Reset the alarm, then run the clamp and release three times at setup speed and confirm the sensor lamp every time. Run one automatic cycle under supervision before returning the machine to production. If the alarm returns within the same shift, record what you changed and contact Kaban Machine Technical Service rather than resetting repeatedly.

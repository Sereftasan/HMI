# Requests for Claude

Write here what is missing or wrong, whenever you notice it - one line or a paragraph each, in any order.
Claude reads this file at the start of every batch, does the items, and moves each one to "Done" with its commit.

**Screenshots and other files** (a picture of the panel, a PLC label export, a drawing, an Excel list): put them in
the **`_requests`** folder beside this file and write the file's name in the item, e.g.
`- The Axis Monitor's last column is cut off at 150% - see _requests\axis_monitor_150.png`.
Any name and format will do (PNG, JPG, PDF, XLS, CSV, TXT ...). Claude opens and looks at them; they are not part of
the program's code (git leaves the folder out). In a chat message you can also paste a picture directly.
